Malware -> Malicious Software

                    MALWARE
                       |
        ---------------------------------
        |        |       |       |       |
      Virus     Worm   Trojan  Ransomware  Spyware

1. Virus

Attaches itself to another legitimate file/program and spreads when that file is executed.

The biggest keyword:
HOST FILE REQUIRED




| Scenario                       | Answer         |
| ------------------------------ | -------------- |
| Needs host file                | **Virus**      |
| Self-replicates across network | **Worm**       |
| Disguised as useful software   | **Trojan**     |
| Encrypts files and asks money  | **Ransomware** |
| Secretly monitors activity     | **Spyware**    |
| Records keyboard strokes       | **Keylogger**  |
| Shows unwanted ads             | **Adware**     |
| Hidden privileged access       | **Rootkit**    |
| Activates on condition/date    | **Logic Bomb** |
| Network of infected machines   | **Botnet**     |




One source floods server
        → DoS

Multiple sources flood
        → DDoS

        → HTTP Flood

Intercept communication
        → MITM

Fake Wi-Fi same SSID
        → Evil Twin

Fake IP-MAC mappings
        → ARP Spoofing

Fake DNS mapping
        → DNS Spoofing

Information gathering
        → Reconnaissance

Spoofed ICMP + broadcast
        → Smurf Attack

Malformed/oversized ping
